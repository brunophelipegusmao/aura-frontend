Aura Activewear — pacote de assets (sem alterar a arte)

O que tem aqui
- logo/: versões do logo em PNG / WebP / JPG em vários tamanhos (útil para responsivo).
- favicon/: favicon.ico (multi-size) + PNGs 16/32/48/64.
- icons/: ícones comuns para PWA e Apple touch (57 até 1024).
- social/: imagens prontas para Open Graph e Twitter (com padding na cor do fundo original).

Sugestões de uso rápido
- /favicon/favicon.ico                -> favicon padrão
- /favicon/favicon-32x32.png         -> <link rel="icon" type="image/png" sizes="32x32" ...>
- /icons/icon-180x180.png            -> Apple touch icon
- /icons/icon-192x192.png e 512x512  -> PWA (manifest.json)
- /social/og-1200x630.png            -> meta property="og:image"
- /social/twitter-1200x675.png       -> meta name="twitter:image"

Observação
- O arquivo SVG aqui é um “wrapper” com a imagem embutida (não é vetor real).
